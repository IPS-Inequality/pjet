# Emissions Profile Sources

The API uses these aircraft profiles for the adapted Travel Impact Model implementation. Each profile stores a fuel-use source and a speed source in `server/index.js`; the selected profile and citations are returned with every estimated event.

The original `bizjet-impact-calculator` introduced Phenom 300, Citation CJ4, Gulfstream G650, and Global 7500 constants as local demo data in its initial `app.py` commit, without per-profile citations. Its README references Conklin & de Decker-derived summaries as implementation background, but it does not map individual constants to source rows. For this API, the seed profiles below use direct public model sources where a matching fuel or speed value is available.

The generic business-jet fallback is displayed as `Generic business jet (CJ4 assumptions)` and uses the Citation CJ4 values below, but its `profileSource` is `business_jet_fallback` rather than `model_match`. Model matching is intentionally strict: profiles match explicit model-name and model-code aliases, not broad manufacturer or family strings. Obvious airliners, regional jets, piston aircraft, trainers, and rows with no aircraft model text are excluded from the generic fallback.

The exact per-profile citations are returned in API responses and stored beside each profile in `server/index.js`.

For numeric Cessna rows where the local metadata only contains a type-code-like model string, the profile uses a named assumption for that code instead of inferring a newer variant. For example, bare `CESSNA 550` maps to Citation II 550 assumptions, while explicit `Citation Bravo` text maps to Citation Bravo. Bare `CESSNA 560` maps to Citation V 560 assumptions, while explicit Ultra/Encore text maps to the Ultra/Encore profile.

These counts were measured on PJET's earlier event ledger, before it switched to adsbfi-proxy data. After rebuilding `aircraft.sqlite` with stricter aircraft-type classification, rows labeled `business_jet` total 15,549,857 flights. Of those, 15,376,103 flights now have source-backed model matches, 154,268 still use the generic CJ4 fallback, and 19,486 are excluded from the fallback because they are obvious non-business rows or have no aircraft model text. Source-backed coverage across the non-excluded business-jet rows is 99.01%; total estimated coverage across all corrected business-jet rows is 99.87%. The largest remaining fallback blocker is the family-only `Embraer Phenom` model string at 143,892 flights; it cannot be grounded to Phenom 100 vs Phenom 300 from the model string alone.

## Fallback Exclusions

Some aircraft metadata rows are typed as `business_jet` even when the model string is not a business jet or is missing entirely. These are excluded before the generic business-jet fallback is considered.
